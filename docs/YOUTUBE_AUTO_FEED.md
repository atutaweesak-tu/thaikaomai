### RSS
- `GET https://www.youtube.com/feeds/videos.xml?channel_id=UC…` จาก **backend เท่านั้น** (หน้าเว็บไม่เรียก YouTube)
- เก็บ: Video ID, ชื่อ, URL, Thumbnail, วันที่เผยแพร่, ประเภท + เหตุผล (`classifyEvidence`)
- **ตรวจช่องทุกรอบ:** `yt:channelId` ใน feed ต้องตรงกับ Channel ID ที่ตั้ง — ไม่ตรง / 404 / ได้หน้า HTML = ไม่นำเข้าอะไรเลย
- RSS แปลง `@handle` เป็น Channel ID ไม่ได้ (ไม่มีวิธีทางการ ไม่ scrape) → **ต้องใส่ Channel ID (UC…)** จาก YouTube Studio › การตั้งค่า › ช่อง › การตั้งค่าขั้นสูง · ถ้าลิงก์เป็น `/channel/UC…` ระบบอ่าน ID จากลิงก์ได้
- RSS ให้ ~15 คลิปล่าสุดเท่านั้น (ไม่มีย้อนหลัง/ความยาว/สถานะไลฟ์)

### การจำแนก Shorts (ไม่ใช้ความยาวตัดสิน)
| ข้อมูล | ผล |
|---|---|
| RSS: ลิงก์ entry เป็น `/shorts/ID` | Shorts (ยืนยันแล้ว) |
| RSS: `#shorts` ในชื่อ/คำอธิบาย | Shorts แต่ **ประเภทยังไม่ยืนยัน** |
| RSS: ลิงก์ `/watch?v=` | คลิปปกติ แต่ **ประเภทยังไม่ยืนยัน** |
| Data API (มี key) | live/upcoming จาก `liveBroadcastContent`; Shorts = ≤180 วิ **และ** player แนวตั้งหรือ #shorts |

admin กด "เป็นคลิปปกติ / เป็น Shorts" หรือแก้ประเภทในฟอร์ม → ล็อกไว้ ซิงก์ไม่เปลี่ยนกลับ · ข้อมูลที่ยืนยันไม่ได้ไม่ทับประเภทที่ยืนยันแล้ว

### กันซ้ำ / เคารพการจัดการของ admin / ความทนทาน
- คีย์ = YouTube Video ID (รวมคลิปที่ admin เพิ่มเองด้วยลิงก์) → ไม่มีซ้ำ, คลิปเพิ่มเองไม่ถูกแตะ
- ไม่แตะ ชื่อ/ซ่อน/ปักหมุด/ลำดับ/คลิปเด่น ที่ admin ตั้ง · คลิปที่ซ่อนยังซ่อน · คลิปจาก sync ที่ลบไม่ถูกเพิ่มกลับ
- คลิปใหม่ขึ้นลำดับแรก · ซิงก์ล้มเหลว = ไม่แตะ `videos.json` + แจ้งใน admin ("หน้าเว็บยังแสดงคลิปชุดเดิม")

## ยังใช้งานไม่ได้ / สิ่งที่ขาด

1. **ยังไม่มี Channel ID จริงของช่องพรรค** — ในระบบมีแค่ลิงก์ `https://www.youtube.com/@thaikaomai` (handle) ซึ่ง RSS แปลงเป็น ID เองไม่ได้ และผมไม่สร้าง/เดา ID ขึ้นเอง → ต้องให้ผู้ดูแลช่องคัดลอก Channel ID (UC…) มาใส่ในแท็บคลิปวิดีโอ
2. **ยังไม่ได้ยืนยันกับ YouTube RSS จริง** — ลองเรียก RSS สาธารณะของช่องอื่นจากเครื่องนี้ 2 ช่องได้ **404** ทั้งคู่ (YouTube RSS เคยตอบ 404 เป็นช่วงๆ หรือ ID ที่ผมลองอาจไม่ถูก) จึงทดสอบได้กับ mock เท่านั้น — ระบบรองรับกรณีนี้แล้ว (บันทึกแต่ "ยังไม่ยืนยัน", ไม่นำเข้า, แจ้งใน admin)
3. **รูปแบบลิงก์ Shorts ใน RSS จริงยังไม่ได้ยืนยัน** — ระบบถือว่า `/shorts/` = Shorts; ถ้า feed จริงใช้ `/watch` ทุกคลิป Shorts จะขึ้นเป็น "ประเภทยังไม่ยืนยัน" ให้ admin กดกำหนด (ไม่ผิดประเภทเงียบๆ)
4. RSS ไม่บอกไลฟ์/ความยาว และมีแค่ ~15 คลิปล่าสุด — ใส่ `YOUTUBE_API_KEY` ฝั่ง server เมื่อพร้อม ระบบสลับไปใช้ Data API อัตโนมัติ (ดู `docs/YOUTUBE_CHANNEL_SYNC.md`)
