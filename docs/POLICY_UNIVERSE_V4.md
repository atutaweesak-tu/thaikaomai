# Policy Universe V5 — ธนู 4 ดอก (Horizontal / Vertical Accordion)

ส่วน "ธนู 4 ดอก" บนหน้าแรก (`policyUniverse` block) — คอมโพเนนต์ `src/components/uf/PolicyUniverse.tsx`

- **เดสก์ท็อป (≥ 1024px / `lg`):** Horizontal Accordion — 4 แถบเรียงแนวนอน แถบที่เลือกขยายโชว์รูป + รายละเอียด
- **มือถือ / แท็บเล็ต (< 1024px):** Vertical Accordion — กดดอกไหน รายละเอียดกางใต้ดอกนั้นทันที

> ประวัติ
> - V4 (ต้นฉบับ "4 Synchronized Arrows"): เลนพลังงาน 4 สาย + comet วิ่ง + เส้นเชื่อมแนวตั้ง + เส้นโค้งรวมเข้าวง SYNERGY, แผงรายละเอียดด้านขวา (มือถือ: แผงอยู่ใต้เลนทั้งหมด ปัดซ้าย-ขวาเปลี่ยนดอก)
> - V4.1–V4.3: ทดลองข้อความ/จุดบรรจบ/วงกลม แล้วกลับมาใช้ V4
> - **V5 (2026-11-10, commit 5c5cb4d):** เอาเส้นพลังงานทั้งหมดออก — บนมือถือส่วนตกแต่งกินความกว้าง ~1/3 จนชื่อนโยบายเหลือ 13px และตัดบรรทัดกลางคำ ("พลิกโฉมการ/ศึกษา") และกดเลือกแล้วแผงที่เปลี่ยนอยู่นอกจอ มองไม่เห็นว่าเกิดอะไรขึ้น

## เดสก์ท็อป — Horizontal Accordion
| สถานะ | หน้าตา |
|---|---|
| แถบที่หุบ (`flex-grow: 1`) | รูปของดอกนั้นจาง (opacity 30%, saturate 50%) + gradient มืด · เลข 01–04 ด้านบน · ชื่อ + จำนวนนโยบายด้านล่าง (ตัวอักษรแนวนอน ไม่หมุน) |
| แถบที่ขยาย (`flex-grow: 4`) | รูปเต็มความกว้าง สูง 240px + ป้าย "เลข + ธนูดอกที่ N" มุมซ้ายบน · ชื่อ (h3) · คำอธิบาย (สูงสุด 3 บรรทัด) · นโยบาย 3 ข้อแรก + "และอีก N นโยบาย" · ปุ่ม "อ่านนโยบายฉบับเต็ม" |

- ความสูงทั้งแถวคงที่ 580px · ขอบแถบที่เลือกเป็นสี lemon + glow
- **เปลี่ยนดอกได้ 3 ทาง:**
  - **ชี้เมาส์ค้าง 180ms** (hover intent — ลากผ่านเฉย ๆ ไม่สลับ) · เอาเมาส์ออกแล้วแถบยังเปิดค้าง ไม่หุบกลับ
  - **คลิก**
  - **คีย์บอร์ด:** tablist แนวนอน — ลูกศรซ้าย/ขวา (ขึ้น/ลงก็ได้) · Home = ดอกแรก · End = ดอกสุดท้าย · roving tabindex
- ปุ่ม tab เป็น element เดียวกันทั้งตอนหุบ (คลุมทั้งแถบ) และตอนขยาย (ป้ายมุมรูป) — focus ไม่หลุดตอนสลับด้วยคีย์บอร์ด
- แถบขยายด้วย CSS transition `flex-grow` 500ms · เนื้อหาในแถบที่ขยาย fade-in หลังดีเลย์ 250ms และล็อก `min-w-[480px]` — ข้อความไทยไม่ไหลตัดบรรทัดใหม่ระหว่างแถบกำลังกว้างขึ้น

## มือถือ / แท็บเล็ต — Vertical Accordion
- แถวละดอก กว้างเต็มจอ สูงอย่างน้อย 68px: เลข 01–04 · ชื่อ 15px · จำนวนนโยบาย · ลูกศรลง (หมุนเมื่อเปิด)
- กดดอกไหน รายละเอียด (`PillarDetail`: รูป 16:7, คำอธิบาย, นโยบาย 5 ข้อแรก, ปุ่มอ่านฉบับเต็ม) กางใต้ดอกนั้น · เปิดได้ทีละดอก · กดซ้ำเพื่อพับ
- เริ่มต้นเปิดดอกที่ 1
- ถ้าดอกที่เปิดอยู่ด้านบนพับลง หัวข้อที่เพิ่งกดอาจเลื่อนพ้นจอ → หลัง animation กางจบ (`onAnimationComplete`) เลื่อนหน้าให้หัวข้อกลับมาอยู่ใต้ Navbar (ไม่ใช้ setTimeout เพราะ animation อาจช้ากว่าที่คาด)
- ARIA: `aria-expanded` / `aria-controls` + แผง `role="region"`

## Motion
- **Reduced motion:** แถบ/แผงสลับทันที ไม่มี transition (`motion-reduce:transition-none`, motion `initial={false}`)
- **โหมดสำรวม (admin):** กฎเดิมของเว็บ
- ไม่มี animation วนซ้ำแล้ว (ลบคลาส `uf-sync-*` ออกจาก `src/index.css`)

## ทดสอบ
- มือถือ (จำลอง 390px): ชื่อไม่ตัดกลางคำ · กางดอก 4 ขณะดอก 1 เปิดอยู่ → หัวข้อดอก 4 อยู่ในจอ · type-check · build
- เดสก์ท็อป: ยังไม่ได้เปิดดูในเบราว์เซอร์ตอนทำ (ส่วนขยาย Chrome หลุด) — ควรเช็กบนเว็บจริง: ชี้/คลิก/คีย์บอร์ด, จอ 1024–1280px

## ข้อจำกัด
- รองรับ 4 ดอกพอดี (แสดง 4 กลุ่มแรก)
- จอ 1024–1280px แถบที่หุบแคบ ~130–160px — ชื่อยาวอาจตัด 2–3 บรรทัด
- รูปในแถบที่ขยายถูก crop เป็น 240px สูง (`object-cover`) — ด้านซ้าย-ขวาของรูป 16:7 อาจหายบางส่วน
- ดอกที่ไม่มีรูป แถบจะเป็นพื้นเรียบ
- คำอธิบายยาวเกิน 3 บรรทัดถูกตัด (`line-clamp-3`) บนเดสก์ท็อป — ข้อความเต็มอยู่ในหน้า /policies
