## 2. Hero V3

- **โหมดเดิมครบ:** `cinematic` · `split` · `imageOnly` · `full` — อ่านค่าจาก admin เสมอ (ทดสอบสลับผ่านหน้า admin จริงแล้ว ดู QA)
- **ฉาก cinematic ใหม่ (SVG/CSS + Motion เดิม ไม่ใช้ WebGL):** เส้นทางโค้งขึ้นขวาบนแบบมีมิติ — **แยกจากโลโก้ชัดเจน** (โลโก้คือลูกศรเส้นตรงในกรอบสี่เหลี่ยม; ฉากนี้เป็นเส้นโค้ง ไม่มีกรอบ), วงโคจร 3 วง, เส้นแสง lemon/cyan, อนุภาคกระจก 6 ชิ้น, พื้นหลังแสง navy ลึก
- **Storyboard:** 0–0.4s ข้อความ + CTA พร้อมใช้ (ไม่เริ่มจาก opacity 0 อีกต่อไป — V2 ปุ่มรอ 1.5s) · 0.4–0.9s ชีพจรพลังงานวิ่งตามเส้นทาง · 0.9–1.5s วงโคจร + เส้นแสง · 1.5–2.0s อนุภาค · >2s ลอยเบาๆ + ชีพจรซ้ำทุก ~5.5s
- **ลด motion / โหมดสำรวม:** ทุกชั้นนิ่งในสถานะสุดท้ายทันที (ชีพจรซ่อน) · มือถือ: เล่น intro ครั้งเดียว ไม่มีการวนซ้ำ
- **มือถือ:** เรียงบน-ล่าง (ข้อความ → ปุ่ม 2 ปุ่มแถวเดียว → แถบภาพ 180px) — 390px สูง **610px** (V2 498 แบบลูกศรหลังข้อความ / เป้า 500–650); 320–360px ปุ่มขึ้นสองแถว = 672px (ขยายตามเนื้อหา)
- **imageOnly / ประกาศถวายอาลัย:** ภาพเดิม ไม่ครอป ไม่มีเอฟเฟกต์ทับ — เพิ่มกล่องจองพื้นที่ 16:9 ก่อนภาพโหลด (เดิมเนื้อหาใต้แบนเนอร์กระโดด)

## 5. กิจกรรมทั่วประเทศ V3

- **ไม่พบไฟล์แผนที่ SVG ขอบเขตจังหวัดที่ได้รับอนุมัติ** → ไม่วาดขอบเขตเอง ใช้ **แผนผังภูมิภาค 6 ภาค** (คณะกรรมการภูมิศาสตร์แห่งชาติ 2520: เหนือ 9 · อีสาน 20 · ตะวันตก 5 · กลาง 22 · ตะวันออก 7 · ใต้ 14 = 77) วางตามทิศโดยประมาณ ระบุบนหน้าจอว่า "ไม่ใช่แผนที่ตามมาตราส่วน"
- จุดนีออนเฉพาะภาคที่มีกิจกรรมจริง (จังหวัดอ่านจากข้อความสถานที่) · ภาคที่เลือกไฮไลต์ lemon · ไม่มี animation วนซ้ำนอกจากจุดเรืองแสงเบาๆ (ปิดเมื่อลด motion)
- Dropdown จังหวัดจัดกลุ่มตามภาค (หลัก) · มือถือ: dropdown ก่อน แล้วปุ่มภาคแบบแถว (รอง) · การ์ดแนวตั้ง
- กิจกรรมแยกกลุ่ม: **กำลังจัด / กำลังจะมาถึง** · **ยังไม่ระบุวัน** · **ผ่านไปแล้ว** (สูงสุด 3 + จำนวนที่เหลือ) · ระดับประเทศ/ไม่ระบุจังหวัด
- **ข่าวที่เกี่ยวข้องในพื้นที่:** ข่าวที่หัวข้อ/สรุปพูดถึงจังหวัดในภาค/จังหวัดที่เลือก (กฎขอบคำเดียวกับการอ่านสถานที่)
- ตรรกะวันที่ V2 คงเดิม: เวลาไทย, `startAt` ก่อนเสมอ, ไม่เดาปี · ไม่สร้างสาขา/สถานที่
- โครงหัวข้อ h2 → h3 (กลุ่ม) → h4 (การ์ด) — แก้ `heading-order` จาก V2

## 6. ความต่อเนื่องของภาพ + ระยะห่าง

- `JourneyBackdrop`: คง grid + เส้นแสงเดิม · เพิ่มชั้นหมอกลึก (คาบ 2600px) · โซนแสงเปลี่ยนจาก % ความสูงหน้าเป็น **จังหวะซ้ำทุก 1800px จากซ้ายบน** — สม่ำเสมอไม่ว่า admin จะจัด/ซ่อน section อย่างไร ไม่มีโซนมืดยาว · **รอยต่อแสงบางๆ ระหว่างทุก section ที่ติดกัน** (CSS ไม่ผูกลำดับ block)
- ระยะห่าง: ตรวจกล่องจริงแล้วปรับเฉพาะจุดที่เกิน — แผนผังภูมิภาคเตี้ยลง (กิจกรรม 933 → 875px), คอนโซลผู้ช่วยมือถือวางอวตารข้างคำทักทาย (838 → 736px), padding คอนโซลเดสก์ท็อป (663 → 647px); ไม่ลดทุก section แบบเหมารวม
